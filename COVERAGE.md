# Content coverage — version 3

56 distinct numerical problem structures, 77 authored recall prompts and 53 authored written explanations. A shared numerical structure assigned to two related topics is counted once in the total, but appears in both rows. Numerical seeds vary values; they do not increase the structure count.

Every broad topic in Maths, OCR A Physics, Edexcel Chemistry and Core Pure + FM1/FM2/FS1/FS2 has at least one supported type. This does **not** mean every specification statement or exam question style is covered. Further Pure 1/2 and Decision 1/2 remain outside this content expansion.

A dash means no authored content for that type: the planner excludes it. Mark ranges: recall 1–2, written explanation 4–6, numerical/problem solving 7–12. Marks are practice points, not official board assessment. Conceptual prompts are finite and recur; most topics currently have one prompt per supported conceptual type.

## Extending the collection

Add an original builder to public/template-library.js using add(id, topicIds, title, build). Use constrained parameters and compute answers from the same mathematical model; include parameters and numerical answers for tests. Every long problem must have at least two labelled parts whose [marks] sum to the number of marking points. Add conceptual prompts to public/concept-library.js with one distinct point per practice mark and a connected model answer. Never scrape/paywall-bypass or copy a publisher’s question bank. Run npm test and node scripts/coverage.mjs, then commit and redeploy.
